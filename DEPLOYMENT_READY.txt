🚀 QUICK START (5 MINUTES)
═══════════════════════════════════════════════════════════════════════════════════

1. Download and transfer to Raspberry Pi:
   $ scp -r offline/ pi@192.168.1.100:~/

2. SSH into Raspberry Pi:
   $ ssh pi@192.168.1.100

3. Run automated setup:
   $ cd offline-ai-reader
   $ bash setup_raspberry_pi.sh

4. Start the application:
   $ python3 app.py api

5. Access in web browser:
   http://<pi-ip>:5000


THAT'S IT! The application is now running! 🎉

📊 API CAPABILITIES (12 Endpoints)
═══════════════════════════════════════════════════════════════════════════════════

Document Management:
  • GET /api/documents - List all documents
  • GET /api/documents/{id} - Get document
  • DELETE /api/documents/{id} - Delete document

Scanning:
  • POST /api/scan - Upload and scan image
  • POST /api/capture - Capture from camera

Search & Analysis:
  • GET /api/search - Full-text search
  • POST /api/documents/{id}/analyze - AI analysis
  • POST /api/documents/{id}/summarize - Summarization
  • POST /api/documents/{id}/ask - Q&A system

Export & Info:
  • GET /api/documents/{id}/export - Multi-format export
  • GET /api/stats - Application statistics
  • GET /api/health - Health check
